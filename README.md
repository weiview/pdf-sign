# PDF 編輯簽章

單一檔案的網頁工具（`index.html`），在瀏覽器裡編輯 PDF、簽名。**檔案不會上傳**，全部在本機處理。

## 怎麼用

**線上直接用：https://weiview.github.io/pdf-sign/**（手機也可以）


直接用瀏覽器（Chrome／Edge／Safari／Firefox）開 `index.html` 即可；需要連網載入
pdf.js、pdf-lib 與 Google Fonts（jsDelivr／Google CDN）。

也可以起一個本機伺服器：

```bash
python3 -m http.server 8000
```

## 功能

- **標註**：文字（中文 OK，黑體／明體、大小、顏色）、手寫、螢光筆、塗白、今天日期、打勾、圖片／印章
- **簽名**：手寫（有筆壓感的線條）、打字（毛筆／行書／草書／英文草寫體）、上傳圖片（可自動去白底）；
  可存進「我的簽名」（瀏覽器 localStorage，最多 8 個）
- **打字簽名的字型**（繁體都完整，全部 SIL OFL 開源授權、可商用）：
  落雁（辰宇落雁體 2.0）、清松手寫體 5／6／7、芫荽（Iansui）、悠哉（Yozai）、楷書（霞鶩文楷 TC）。
  落雁與清松每套 4～9 MB，第一次選到時才下載。毛筆／行書／草書是簡體字型，繁體常缺字，
  選到時會列出缺哪幾個字。
- **頁面**：旋轉、上下移、插入空白頁、刪除、把另一份 PDF 合併到最後
- 拖曳移動、右下角圓點縮放、複製、刪除；`Ctrl+Z` 復原、方向鍵微調（Shift 一次 10px）
- **草稿**：
  - 自動草稿：每次改動後自動存在這個瀏覽器裡（IndexedDB），下次打開會問要不要「繼續編輯」。
    只存最近一份；換電腦、換瀏覽器或清掉瀏覽器資料就沒了。
  - 草稿檔：按「存草稿」下載 `.pdfdraft`（原本的 PDF ＋ 還能修改的標註），之後用「開啟」或拖進來就能接著改，可以帶到別台電腦。
  - 「下載 PDF」是把標註合進 PDF 另存新檔，原檔不動；合進去之後就不能再移動或修改，所以要留著修改的空間請另外存草稿檔。
- 快捷鍵：`V` 選取、`T` 文字、`S` 簽名、`D` 手寫、`H` 螢光筆、`W` 塗白、`Esc` 結束工具、`Ctrl+S` 下載

## 要知道的限制

- **簽名是「圖像簽名」，不是數位憑證簽章**（沒有 PKCS#7／自然人憑證那種可驗證的簽章）。
- **塗白只是蓋一塊色塊**，底下的文字仍然選得到、複製得到，不能拿來刪除機密資料。
- 文字標註下載時會轉成高解析度圖片固定進 PDF（為了支援中文字型），所以之後不能再被選取成文字。
- 有密碼保護（加密）的 PDF 打不開，要先用原本的軟體移除密碼。
- 旋轉頁面時，那一頁已經放上去的標註會先固定進 PDF（才會跟著一起轉），之後就不能再移動。
